# Contributing to Sysmic

Thank you for your interest in contributing to **Sysmic**! We are an open science project dedicated to democratizing access to advanced geophysical analysis tools.

## Code of Conduct

All contributors are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). We are committed to providing a welcoming community for everyone.

## How to Contribute

### 1. Reporting Bugs
- Ensure the bug was not already reported.
- Open a new Issue with a clear title and detailed description.
- Include a minimal reproduction example if possible.

### 2. Suggesting Enhancements
- Open a new Issue with the `enhancement` label.
- Describe the feature you would like to see and why it is useful.

### 3. Pull Requests
- Fork the repository.
- Create a new branch (`git checkout -b feature/AmazingFeature`).
- Commit your changes (`git commit -m 'Add some AmazingFeature'`).
- Push to the branch (`git push origin feature/AmazingFeature`).
- Open a Pull Request.

## Scientific Validation
Any algorithmic change must pass the **Triple Validation Protocol**:
1.  **Synthetic Testing**: Verify on Cantor sets and Sierpinski carpets.
2.  **Regression Testing**: Ensure no degradation on the `SanAndreas_2010_2025` benchmark dataset.
3.  **Literature Alignment**: Results must align with established scaling laws (Gutenberg-Richter, Omori).

## Style Guide
- **Python**: Follow PEP 8.
- **Documentation**: Use clear, concise language (English/Spanish/Portuguese).
- **Commits**: Use conventional commits (e.g., `feat: add multifractal spectrum`, `fix: resolve bootstrap convergence`).
